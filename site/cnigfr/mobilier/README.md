# Mobilier

## Définition

Le mobilier est un équipement installé le long ou à proximité d’un cheminement, destiné à servir, faciliter ou améliorer l’usage du parcours et le confort des usagers.

## Sélection

Tous les mobiliers installés le long ou à proximité d’un cheminement

## Modélisation géométrique

Ponctuel 3D recommandé. Ponctuel 2D possible.
